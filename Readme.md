# 🗓️ Telegram Bot для записи на приём

Проект: Telegram-бот для онлайн-записи клиентов на услуги (например, маникюр, стрижка, консультации и т.д.).  
Бот позволяет владельцу управлять расписанием через админ-панель, а клиентам — записываться на свободные слоты.

Проект выполнен в рамках лабораторной работы по Git (работа в паре, один репозиторий).

---

## 🚀 Возможности

### Для клиентов:
- Просмотр доступных дат и времени
- Запись на свободный слот
- Получение подтверждения записи

### Для администратора (владельца бота):
- Добавление свободных слотов для записи
- Просмотр записей клиентов
- Удаление / редактирование слотов
- Управление направлениями услуг (универсальная система)

---

## 🛠️ Планируемый функционал

- Поддержка нескольких услуг (например: маникюр, педикюр, консультация и т.д.)
- Разделение ролей: пользователь / администратор
- Хранение слотов и записей (файл или база данных)
- Удобное меню в Telegram (кнопки)
- Простейшая админ-панель через команды бота

---

## 🧱 Технологии (план)

- Python
- Telegram Bot API (например, через aiogram или `pyTelegramBotAPI`)
- Git + GitHub для совместной разработки

---

## 📂 Структура проекта (план)

- bot.py — основной файл бота  
- handlers/ — обработчики команд и кнопок  
- data/ — хранение слотов и записей  
- config.py — настройки и токен бота  
- README.md — описание проекта  

---

## 👥 Работа в паре

Проект разрабатывается в одном репозитории двумя участниками:

- Участник 1: инициализация репозитория, базовая структура проекта, логика бота
- Участник 2: доработка функционала, логика записи, работа с данными, улучшения интерфейса

История коммитов отражает вклад каждого участника.
